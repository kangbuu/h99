# 半杯

**少喝一点，记清楚一点。**

半杯是一款纯本地的饮酒记录与酒精估算工具（HarmonyOS / 包名 `com.h99.app`，历史代号 H9）。

## 隐私政策

完整隐私政策：<https://kangbuu.github.io/h99/>

本应用无账号、无业务服务器、无广告与统计 SDK；昵称、身体数据与饮酒记录仅保存在设备本地，可随时删除或卸载清除。
